# Иселган — интерактивная 3D-сцена

[Открыть 3D-сцену](https://alexskuka.github.io/iselgan_ext/)

Детализация выбирается в настройках. Авто использует лёгкую модель для
сенсорного управления, подробную — для мыши. Полная модель обучена до
30000 обновлений; облегчённые копии прошли отдельное восстановление.

Автоматический облёт: круг за 60 секунд, ▶/Ⅱ — запуск и пауза.
Ручное управление останавливает облёт. Мышь или жесты — осмотр;
WASD/стрелки — перемещение, R — исходный вид, F — вся сцена.
Скорость перемещения соответствует последней настройке пользователя.

Светлая кайма лесного горизонта и местами размытые/растянутые детали
остаются в модели. Лёгкая версия мягче передаёт мелкие детали.

Папка содержит готовый статический сайт для GitHub Pages: ветка `main`,
источник `/ (root)`, `.nojekyll`. Внешний backend не требуется.
